# AI 提问框 · Obsidian AI Question Box

在笔记中提问，让 AI 把答案留在问题旁边。

AI 提问框为 Obsidian 桌面端提供固定样式的问答区域，复用 [Claudian](https://github.com/YishenTu/claudian) 的 Claude 配置生成答案。可以边读边问，也可以一次回答整篇文档中的所有问题。

**当前版本：1.1.2** · 中文界面 · 桌面端 · 已验证 macOS、Obsidian 1.13.7、Claudian 2.0.31。

## 能做什么

- **即问即答**：输入问题后提交，自动生成答案，无须另开聊天窗口。
- **批量回答**：扫描当前笔记的提问标记，回答未答问题，或重新回答全部问题。
- **同框阅读**：外层是问题框，内层是答案框；追问接在原答案下面。
- **默认收起**：打开或重新进入文章时，答案默认收起，点击「AI 答案」展开。
- **稳定选字**：实时预览中拖动选中文字，框不会变成源码。
- **持久高亮**：问题和答案都可高亮，重新打开笔记仍能看到。
- **右键追问**：答案内右键选择「追问」；可引用选中的片段，也可针对整条答案提问。
- **可调外观**：问题和答案分别设置底色、边框，浅色与深色模式独立配置。
- **编辑保护**：生成期间原框被修改时，保留手动编辑，并允许复制未写回的结果。

显示结构如下。追问不会再次展示整段原问题和引用，但 AI 会获得相关上下文。

```text
提问：这个概念是什么意思？
┌ AI 答案（点击展开 / 收起）
│ 解释、例子……
└
追问：这里为什么这样做？
┌ AI 答案（点击展开 / 收起）
│ 针对疑问的补充解释……
└
```

## 安装前准备

需要先完成这三步：

1. 安装 Obsidian 桌面版。插件声明的最低版本为 1.7.2；使用 Claudian 时，还需满足所安装 Claudian 版本自己的最低要求。建议使用当前稳定版。
2. 安装并启用 Claudian。本插件兼容验证针对 **2.0.31**；其他版本可能需要适配。
3. 安装 Claude Code CLI，并在 Claudian 中选用 **Claude**，确认能够正常发送一条消息并收到回答。

本插件只接入 Claudian 的 Claude 提供商，不接入其 Codex、OpenCode、Pi 等提供商。不支持手机或平板上的 AI 调用。Windows/Linux 尚未做实机验证；Windows 优先使用原生 `claude.exe`，本插件不会通过 shell 执行 `.cmd` 或 `.ps1` 包装脚本。

详细操作见 [配置说明](docs/CONFIGURATION.md)。

## 安装插件

当前通过手动安装使用，不需要运行源码构建，也不代表已上架 Obsidian 社区插件市场。

### 方式一：从 GitHub 项目下载

1. 在项目页面点击 **Code → Download ZIP** 并解压。
2. 在你的 Obsidian 仓库中找到 `.obsidian/plugins/`。没有 `plugins` 文件夹时手动创建。
3. 新建文件夹 `ai-question-box`，把下载目录中的以下三个文件复制进去：

```text
你的仓库/
└── .obsidian/
    └── plugins/
        └── ai-question-box/
            ├── main.js
            ├── manifest.json
            └── styles.css
```

4. 重新打开 Obsidian，在 **设置 → 第三方插件** 中启用 **AI 提问框**。
5. 打开 **设置 → AI 提问框**。顶部应显示 Claudian 的连接状态和模型。

macOS Finder 中可按 `Cmd + Shift + .` 显示隐藏目录。插件文件夹的名字必须是 `ai-question-box`，不要直接使用下载 ZIP 解压得到的项目文件夹名。

### 方式二：已有安装包

如果获得 `ai-question-box-版本号.zip` 安装包，将里面的 `ai-question-box` 文件夹放进 `.obsidian/plugins/`，之后按上面的步骤启用。

### 更新与卸载

更新时先停止正在生成的任务、禁用插件，再替换三个运行文件并重新启用。**保留 `data.json`**，它保存颜色、回答要求和超时设置。不要用其他人的配置覆盖它。

禁用或卸载插件不会删除笔记中的问题与答案。它们是 Markdown；固定显示、高亮还原和同框追问归组需要启用本插件。

## 第一次使用：一分钟问答

1. 新建一篇笔记，写下学习材料或文章正文，也可以复制 [入门示例](examples/快速开始.md) 到仓库中。
2. 把光标放在想提问的位置，按 `Cmd/Ctrl + P` 打开命令面板。
3. 搜索 **AI 提问框：插入提问框**，输入问题，例如「请结合上文解释这个概念，并举一个简单例子」。
4. 点击 **插入并生成答案**，或按 `Cmd/Ctrl + Enter`。
5. 生成结束后，点击框中的 **AI 答案** 标题展开阅读。

「立即生成」表示提交后立即开始请求；实际等待时间取决于文档长度、模型和网络，当前不会边生成边显示正文。答案成功返回后一次性写入。

如果只想先记下问题，选择 **仅插入**。在普通正文中右键也可选择 **插入 AI 提问框**。插入前若选中了文字，这段文字会预填为问题，并由问题框替换原选区；不要选中希望原样保留在正文中的整段资料。

## 日常操作

### 批量回答与单题重答

- 问题框顶部的 **AI 回答**：回答或重新回答这一题。
- **回答当前文档所有未答问题**：只处理答案为空的提问框。
- **回答／重新回答当前文档所有问题**：逐题生成并替换答案，包括追问。
- **回答光标所在的问题**：在源码模式下，把光标放进目标框后执行。

批量任务逐题执行，同一时间只运行一个生成任务。单题失败后继续处理下一题。已有答案会一直保留，直到新的答案成功返回。

### 折叠答案

打开或重新进入文章时，原答案和追问答案都默认收起；问题文字保持可见。点击 **AI 答案** 标题，或聚焦标题后按 `Enter` / 空格即可展开、收起。

当前阅读中点击展开不会改写笔记。旧版标记也会默认收起，不必重新生成答案；新建答案使用 `[!ai-answer]-`。在插件启用状态下，不用通过修改 `+` / `-` 控制打开时的状态。

### 对答案继续追问

**针对片段：** 展开答案 → 拖动选中有疑惑的文字 → 在选区内右键 → **追问** → 输入疑问 → **提交追问并生成答案**。

**针对整条答案：** 不选文字，直接在答案框内右键 → **追问**。

也可选中文字后点击问题框顶部的 **追问**。对追问生成的新答案，可以继续重复上述操作。新问答按顺序追加在原问题框下方，界面只显示新的问题和答案。每次引用最多 1 万字符。

早期版本生成的追问如果重复展示了原问题和引用，可运行 **整理当前文档旧版追问**，保留答案并转换为简洁显示。

### 高亮、取消高亮与复制

- 选中问题或答案的文字，点击顶部 **高亮**。
- 选中已有高亮的区域，点击 **取消高亮**；相交的高亮标记会整体移除。
- 答案右键菜单在有选区时也提供 **复制 / 高亮 / 取消高亮**。
- 普通正文可运行 **高亮选中文字（普通正文）**，使用 Obsidian 的 `==文字==`。

支持跨粗体等行内格式选择。框内高亮以隐藏注释保存，每框最多 200 处、单次最多 5 万字符。当前高亮颜色为黄色，设置页仅提供问题框与答案框的颜色配置。

重新生成答案会清除该答案的旧高亮，保留问题高亮；编辑文字后，不再匹配原文的标记不会错误地高亮其他内容。

### 修改问题或答案

实时预览中点击问题框顶部 **编辑**，在对话框修改问题和答案后保存。答案支持 Markdown。框是稳定展示区域，不能像正文一样直接键入；需要操作原始标记或删除整个框时，切换到源码模式。

### 查看进度与停止

生成进度面板可选择 **后台继续**。点击底部状态栏 **AI 提问框**，或运行 **查看最近生成结果**，可再次打开面板。

点击 **停止生成** 或运行 **停止生成答案** 可中断当前任务。停止、超时和失败不会写入半截回答。未写回的结果只保存在当前插件运行期间，请在关闭 Obsidian 或重载插件前复制需要的内容。

## 配置入口

打开 **设置 → AI 提问框**：

| 设置 | 用途 |
| --- | --- |
| 问题框底色 / 边框 | 外层提问区域的颜色 |
| 答案框底色 / 边框 | 内部 AI 答案区域的颜色 |
| 深色模式的四项颜色 | 深色主题下独立使用的配色 |
| 回答要求 | 统一设置语言、解释方式、示例要求 |
| 每题最长等待时间 | 30–900 秒，默认 180 秒 |
| 恢复默认颜色 | 只重置颜色，保留回答要求和超时设置 |

颜色即时保存，设置页下方提供预览。文本颜色根据底色自动选择黑色或白色。默认值、回答模板、模型继承和认证排查见 [完整配置说明](docs/CONFIGURATION.md)。

## 所有命令

在命令面板搜索「AI 提问框」，也可在 **设置 → 快捷键** 中为常用命令绑定快捷键。

| 命令 | 使用场景 |
| --- | --- |
| 插入提问框 | 打开输入窗口，提交后立即生成或仅插入 |
| 插入固定提问标记（稍后填写） | 在光标处创建完整的待填写框 |
| 回答当前文档所有未答问题 | 只补充空答案 |
| 回答／重新回答当前文档所有问题 | 批量重答 |
| 回答光标所在的问题 | 源码编辑时指定单题 |
| 停止生成答案 | 取消当前任务 |
| 查看最近生成结果 | 查看成功、失败或未写回的回答 |
| 整理当前文档旧版追问 | 将旧格式转换为同框简洁追问 |
| 高亮选中文字（普通正文） | 给普通正文添加或移除 `==` 标记 |

## 上下文、隐私与数据保存

每题基于当前 Markdown 笔记进行回答。普通问题的文档上下文剔除旧 AI 答案；追问另带原问题、之前的同组问答和选中的引用。不会自动读取整个仓库，也不会展开双链目标、附件或图片内容。资料不足时提示模型说明不足。

文档与问题会发送到 Claudian 的 Claude 配置所指向的服务，可能是 Anthropic 或用户自定义端点，产生相应模型用量。本插件不另存 API 密钥，不添加遥测。为本插件生成答案时，会禁用工具、MCP、hooks 和会话持久化；由插件在成功后把答案写回对应 Markdown 区域。

发送前如果处理后的普通上下文超过 20 万字符，或追问组合上下文超过 25 万字符，会提示拆分，不静默截断。问题及通用回答要求也占模型上下文，请避免粘贴过长指令。

问题与答案保存在笔记中，颜色等配置保存在插件的 `data.json`。高亮、引用、追问关联放在笔记的隐藏注释中；**隐藏不等于加密**，分享 Markdown 时这些元数据也会一起分享。

生成过程中如果目标框被修改或删除，插件会拒绝覆盖；新回答可在进度面板复制。跨设备同步仍依赖 Obsidian 的同步机制，不应在两个设备上同时对同一框发起生成。
