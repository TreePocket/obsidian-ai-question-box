# 常见问题与排查

[返回首页](../README.md) · [配置说明](CONFIGURATION.md)

## 插件没有出现在第三方插件列表

检查是否为桌面版，文件夹是否严格为 `.obsidian/plugins/ai-question-box/`，其中是否直接包含 `main.js`、`manifest.json`、`styles.css`。常见错误是多嵌套一层 ZIP 解压目录。完成后重启 Obsidian。

## 提示先启用 Claudian

确认在当前仓库启用了 Claudian，而不只是其他仓库。打开 Claudian 侧栏，使用 Claude 提供商完成一次普通对话。只配置其他提供商不能让本插件调用 Claude。

## 提示 Claudian 接口不兼容

本插件已验证 Claudian 2.0.31，读取的不是稳定公开 API。检查刚才是否升级了 Claudian，记录双方版本号并提交兼容性问题。不要通过改写 Claudian 源码或绕过报错强行生成。

## 找不到 Claude、无法启动或返回异常

1. 按配置说明检查 CLI 路径是否为实际可执行文件。
2. 在终端确认 Claude Code 可正常启动并已认证。
3. 在 Claudian 的 Claude 会话中验证同一个模型和服务可用。
4. 如果认证/网关来自用户配置，确认开启加载用户设置。
5. 自定义服务检查模型名称、额度和网络；Windows 使用原生 `claude.exe`。

设置页显示「已连接」只说明配置可读，实际生成才验证认证与网络。

## 为什么感觉没有生成答案

答案默认收起，生成成功后点击「AI 答案」标题查看。再检查「查看最近生成结果」中的状态：

| 状态 | 含义与处理 |
| --- | --- |
| 等待中 / 生成中 | 任务尚未结束，当前不是流式正文展示 |
| 已完成 | 答案已写回，展开目标答案框查看 |
| 未写回 | 可能生成失败，或目标框发生变化；查看错误详情及可复制结果 |
| 已停止 / 未执行 | 任务被取消，必要时重新执行 |

若插件提示生成超时，可增加单题等待时间；若提示文档过长，应拆分文档，不是无限增加超时。

## 答案为什么不是基于另一篇双链笔记

普通上下文只来自当前 Markdown 文本；`[[另一篇笔记]]` 不会自动展开。需要 AI 使用的资料应放在当前文档里。图片、PDF 内容和附件也不会自动解析。

## 生成时修改了文字，为什么没有覆盖

这是编辑保护。插件比较目标框的唯一标识与完整原文；问题或答案变化时，保留手工修改。可在最近生成结果中复制回答，再按需要整理。重载插件会清除内存中的最近结果。

## 选中文字后变成源码

确认当前是「实时预览」，插件处于启用状态，并且目标是本插件的 `ai-question` 框。源码模式本来就显示 Markdown。实时预览中使用框顶部「编辑」来改文字。

如果只在某个主题或插件组合中发生，可先在测试仓库使用默认主题检查，再记录冲突插件名称和版本。

## 右键没有追问

右键位置需在 **AI 答案框内**，普通正文仍显示插入提问框。答案为空时先生成答案。旧版安装需要同时更新 `main.js`、`manifest.json` 和 `styles.css`，并重载插件。

无需选择文字也可追问整条答案。若需要引用，先展开答案、选择片段，再在该选区内右键。

## 追问为什么单独显示

确认本插件已启用，且原问题与追问之间没有被手动插入其他正文。生成的关联追问按原有顺序相邻保存，由插件归入原框。

若是早期重复展示「原问题 / 引用 / 我的追问」的旧格式，使用「整理当前文档旧版追问」。不要手动修改隐藏的关联注释或唯一标识。

## 高亮消失或取消范围较大

重答会清除答案高亮；修改了相关段落后，不能匹配的标记也不会继续显示。取消高亮移除与选区相交的完整标记。只在当前选中文字产生的系统选区颜色不是持久高亮，需要执行「高亮」。

框内高亮依赖本插件还原；普通正文的 `==标记==` 是另一种机制。

## 笔记格式报错

问题文字应放在嵌套答案框之前。答案区域之后不要再放外层 `>` 文字；结束整个框后，留空行再写正常正文。

编辑对话框会处理格式。如果手动复制或修改 Markdown，可对照 [格式说明](DEVELOPMENT.md)。

## 反馈问题时提供什么

提供 Obsidian、Claudian、AI 提问框版本，操作步骤，预期与实际行为，以及删去隐私内容的最小示例。不要粘贴 API Key、完整环境变量、登录令牌或未经处理的个人笔记。

本插件在 macOS 进行了实际 UI 和模型调用验证；Windows、Linux、其他主题及后续 Claudian 版本的行为可能不同。
