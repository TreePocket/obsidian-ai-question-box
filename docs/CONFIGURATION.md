# 配置说明

[返回首页](../README.md)

## 1. 先让 Claude 在 Claudian 中工作

AI 提问框不单独提供 API Key 输入框，也没有单独的模型选择器。它读取已经启用的 Claudian 配置，然后调用相同的 Claude Code CLI 发起独立问答。

### 安装 Claude Code

按照 [Claude Code 官方安装说明](https://code.claude.com/docs/en/setup) 完成安装与认证。常见检查方式：

```sh
claude --version
claude
```

先完成 Claude Code 自身要求的登录或服务端认证，确保能正常对话。不同订阅、API 服务和自定义网关的配置不同，以对应服务说明为准。

### 安装和启用 Claudian

在 Obsidian **设置 → 第三方插件 → 浏览** 中搜索 Claudian，安装并启用。也可按照 [Claudian 官方 README](https://github.com/YishenTu/claudian) 手动安装。

打开 Claudian 侧栏，选择 Claude 提供商，发送一个简单问题。收到回答后，再启用 AI 提问框，能减少同时排查多个组件的困难。

已验证版本为 **Claudian 2.0.31**。本插件依赖其运行时接口；以后升级 Claudian 时，需重新确认兼容性。

### Claude 程序路径

通常先使用 Claudian 的自动检测。如果找不到程序，在其 Claude CLI 路径设置中填入实际可执行文件的绝对路径。

macOS / Linux 可以在终端检查：

```sh
command -v claude
```

把命令返回的完整路径填入 Claudian，不要只填写某个文件夹。通过版本管理器安装时，终端能运行不代表 Obsidian 图形界面的环境也能找到程序。

Windows 尚未实机验证。优先使用原生 `claude.exe`；本插件以 `shell: false` 启动指定程序，不能直接把 `.cmd`、`.ps1` 或需 Node 解释执行的 `.js` 路径当作可执行文件。

## 2. 认证与环境变量

插件继承 Claudian 的 Claude 环境变量，并根据 Claudian 的「加载用户设置」开关读取 Claude 用户配置。通过 Claude Code 用户设置管理的认证或网关配置通常需要打开该开关。

使用自定义服务时，在 Claudian 中按服务提供方要求配置。下面只是字段形式示例，**不要把占位符直接当作真实配置**：

```dotenv
ANTHROPIC_BASE_URL=https://your-provider.example
ANTHROPIC_AUTH_TOKEN=YOUR_PROVIDER_TOKEN
ANTHROPIC_MODEL=YOUR_SUPPORTED_MODEL
```

有的服务使用 `ANTHROPIC_API_KEY`，有的使用 `ANTHROPIC_AUTH_TOKEN`，应遵循该服务的说明，不需要全部同时设置。标准 Claude 登录用户不必仅为本插件新增这些变量。

变量解析支持每行 `名称=值`，可加 `export` 前缀及成对引号；不会执行 shell 表达式、命令替换或变量展开。

AI 提问框会使用用户级配置，但问答进程禁用 hooks，不加载仓库项目设置，并禁用 MCP 与工具。它不向当前 Claudian 聊天追加消息，也不继承整段侧栏聊天历史。

### 检查连接

打开 **设置 → AI 提问框**，查看顶部状态：

```text
已连接 Claudian 2.0.31 · 模型 <当前解析出的模型>
```

这个状态代表找到了兼容接口、CLI 路径和模型配置，**不等于已经发起网络请求或验证认证成功**。请插入一个简短问题完成首次生成验收。

## 3. 使用哪个模型

按下面顺序解析模型：

1. 当前活动的 Claude 标签页所用模型。
2. Claudian 保存的 Claude 模型设置。
3. Claude 环境变量中的 `ANTHROPIC_MODEL`。
4. 都没有时回退到 `sonnet`。

实际实现优先读取活动 Claude 服务的模型，再尝试当前会话和草稿模型。切到其他提供商不会让本插件改用该提供商；仍读取已保存的 Claude 配置。

换模型后重新发起生成即可。已经开始的批量任务使用启动时读取的配置；如需全批使用新模型，先停止旧任务再重新开始。

## 4. 问题和答案颜色

浅色、深色模式各有四个独立配置，共八项：

| 设置项 | 默认值 | 对应区域 |
| --- | --- | --- |
| 问题框底色 | `#eef2ff` | 浅色主题外层问题区域 |
| 问题框边框 | `#6366f1` | 浅色主题问题边框 |
| 答案框底色 | `#ffffff` | 浅色主题内层答案区域 |
| 答案框边框 | `#0d9488` | 浅色主题答案边框 |
| 深色模式 · 问题底色 | `#242840` | 深色主题问题区域 |
| 深色模式 · 问题边框 | `#a5b4fc` | 深色主题问题边框 |
| 深色模式 · 答案底色 | `#172f32` | 深色主题答案区域 |
| 深色模式 · 答案边框 | `#5eead4` | 深色主题答案边框 |

点击设置页中的颜色选择器修改，设置立即保存。建议保持问题和答案底色有明显区别；文字会根据底色自动选择黑色或白色。

「恢复颜色」仅重置上述八项，不修改回答要求、等待时间或笔记。高亮标记目前固定使用黄色，不提供单独的高亮颜色设置。

## 5. 回答要求

默认内容：

> 使用中文回答，先直接回答问题，再按需要解释、举例；保留必要的英文术语。

可以替换为下面的模板。它们作用于之后的所有问答，不会自动修改已有答案。

**学习理解：**

```text
使用中文。先用一句话回答，再给出分步骤解释和一个简单例子。
遇到专业术语先解释含义。资料不足时明确说明，不编造来源。
```

**英语语法：**

```text
用中文解释，保留英文例句。依次给出规则、正确例句、常见错误及改正理由。
例句尽量简短，并说明主语、谓语和其他必要成分。
```

**精简复习：**

```text
先直接回答，再给出最多三条要点。默认控制在 200 字以内。
若问题明确要求详细展开，则按问题要求作答。
```

当前问题中指定的语言、字数、句数等要求优先于通用要求。这是提供给模型的指令，输出仍受模型能力影响。

## 6. 等待时间与折叠

每题等待时间默认 **180 秒**，允许输入 **30–900** 的整数。无效值不会保存。长文档或较慢模型可以适当增加，例如 300 秒。

超过等待时间会停止当前请求，保留旧答案。批量任务会继续处理其他问题。

答案打开默认收起是统一行为，当前没有独立的折叠设置开关。点击标题可临时展开；再次进入文章时恢复收起。新问题和新追问也使用收起的答案框。

## 7. 配置文件和迁移

设置保存在：

```text
<仓库>/.obsidian/plugins/ai-question-box/data.json
```

该文件由插件自动管理。迁移自己的外观设置时，可以在停止生成并禁用插件后复制它；正常更新只替换 `main.js`、`manifest.json`、`styles.css`。

本项目不发布个人 `data.json`、认证信息或 Claudian 配置。文档中的问题、答案、高亮和追问关联随笔记 Markdown 一起迁移。新电脑还需独立安装和认证 Claude Code、配置 Claudian。
